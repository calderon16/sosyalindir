# Design_System

- **Özet:** SosyalIndir platformunun renk paleti (Emerald/Teal gradient), typography, dark mode teması ve mikro-animasyon standartlarını belirleyen tasarım sistemidir.
- **Kütüphaneler:** TailwindCSS, Lucide React, Google Fonts (Inter)
- **Bağlantılar:** [[Index]], [[Landing_Page]], [[Navbar]], [[Hero]], [[Url_Input]], [[Video_Preview_Card]], [[Footer]], [[Ad_Slot]], [[Config]]

---

## 🎨 Tasarım Sistem Bileşenleri

- **Renkler:** Slate 950 zemin, Emerald-400 & Teal-300 gradientler.
- **Tipografi:** Sans-serif Inter font ailesi, font-extrabold hero başlıkları.
- **Mikro-Animasyonlar:** Hover scaling, glow efektleri, fade-in bildirim kartları.
